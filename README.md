# Hithyshi PM — Portfolio
React + TypeScript + Tailwind + GSAP (ScrollTrigger).

## Run locally
1. Install Node.js 18+
2. `npm install`
3. `npm run dev`  → open the link shown

## Edit content
All text lives in `src/data.ts`. Your photo is `public/hithyshi.jpg`.

## Deploy
`npm run build`, then upload the `dist` folder to Netlify, or import the repo into Vercel.
